# Hackathon submission

## Project Description (Why is this cool?)

Blockscholar turns learning DeFi into doing DeFi. Built by DRMZ Web3 on Strike Finance, it guides newcomers through six short lessons, an interactive exposure calculator and a real testnet workshop. Learners connect their own wallet, receive sponsored practice funds, review a deposit, then place, inspect and cancel an order directly from Blockscholar. Completion is verified against Strike's API and the same linked account—not a self-reported checkbox.

A verified mission unlocks a 2-test-ADA bounty. A saved field note unlocks 3 more, with on-chain receipts and progress that survives returning to the app. Dream Fund makes the sponsor budget and learning rewards visible. Optional long/short scenarios extend the training, with liquidity checks before execution.

The result is a practical onboarding path that brings new users to Strike while building a foundation for sponsored DeFi education, scholarships and work-based learning. The demo uses Strike testnet and Cardano Preprod; no real funds are required.
