# Hackathon demonstration

**Project:** Blockscholar — sponsored learning with verified Strike practice.

**Pitch:** Most learning platforms stop at a quiz. Blockscholar turns a lesson into a real protocol workflow: connect a test wallet, receive practice funding, review and verify a deposit, place and cancel a real Strike testnet order, then claim a funded Cardano learning bounty. Sponsors see the budget and outcomes through Dream Fund. This provides a concrete path from education to using Strike without asking beginners to risk real funds.

## Three-minute video outline

1. Wallet-only welcome, then Program with three vertical steps and the next activity highlighted.
2. Lessons and exposure calculator; show a saved preparation check.
3. Wallet setup: Cardano Preprod, funding, deposit review, credit verification.
4. Workshop: reviewed post-only order, open-order evidence, cancellation verified against the same account.
5. Claim 2 test ADA, save a field note, claim 3 more, and show Activity complete. Reload to demonstrate saved progress; open Dream Fund for sponsor visibility.
6. Explain the next step: employer-sponsored learning programs and additional protocol missions, clearly labeled as future work.

If testnet liquidity prevents an order or position close, show the real pause message. Never replace it with a fabricated success. Recorded prior user runs can demonstrate the tested workflow, but label which deployment was used.
