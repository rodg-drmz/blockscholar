# Attribution and release boundary

Blockscholar is an independent DRMZ application integrating Strike Finance's public testnet APIs. It is not an official Strike application or a college-endorsed program.

- DRMZ / Blockscholar source and artwork: retained by their respective owners; public for review, no general redistribution license granted here.
- Strike Finance logo and name: protocol identification; rights remain with Strike Finance.
- Six instructional screenshots: example screens produced for the DRMZ Blockscholar workshop, labeled as examples, containing no real learner records.
- Runtime dependencies: Next.js, React, Emurgo Cardano libraries, Midnight signature/address libraries, Noble cryptography, viem and other packages listed in package-lock.json. Their package licenses apply independently.

No proprietary React Bits Pro components or fonts are bundled in this standalone release. The original DRMZ repository and its history are not part of this repository.
